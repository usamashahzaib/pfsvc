Source: live pages fetched through the owner's Chrome. Search Console, 28 days to 2026-10-25: 0 clicks, 29 impressions, average position 3.8, one query ("professional association", 7 impressions).

PFSVC is a freelancer verification council, not a financial services firm. The earlier FinancialService schema template was wrong and is removed.

## Claims to fix before any SEO work (trust and legal risk)

| Claim on site | Problem | Action |
|---|---|---|
| "Official institution in Pakistan", "The Official Standard of Competence" | The FAQ says PFSVC is not a government body. "Official" reads as state-backed and contradicts it. | Replace with "independent". |
| "4,000,000+ Pakistani freelancers. Almost none verifiable." | No source. | Cite a source or remove. UNVERIFIED. |
| Transparency page: "22% acceptance rate", "1,200+ fraud denials" | No method, no period, no source. | Add period and method or remove. UNVERIFIED. |
| "Zero-risk remote Pakistani talent", "zero-risk hiring" | No hiring process can promise zero risk. | Remove. |
| "Globally recognized", "Gold Standard" | No evidence shown. | Remove or support with named clients. |
| Logo strip: Techspirex, Codenest, Launchpad.pk, DevForge Pakistan | Implies these firms hire PFSVC talent. Only Techspirex is confirmed as the owner's company. | Keep only names with written permission. |

| "Biometric liveness", "Sanctions and AML screening", "AI-detection tools" | Strong claims. Confirm each is actually performed. | Owner to confirm. |
