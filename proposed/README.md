# Proposed SEO files for pfsvc.com.pk

Status: REVIEW REQUIRED. Nothing here is live.

This repo holds only a README. It does not contain the code behind pfsvc.com.pk, so these files are proposals. Copy them into the real site's codebase after review.

During this run the live site could not be fetched, so no page was audited and no content about the business is proposed. Writing financial copy without the real facts would risk a compliance problem on a YMYL site.

## Files

- `robots.txt`: allows all crawlers, including search and AI answer engines, and points to the sitemap. The sitemap host is unverified. Change it to the host the site actually serves.
- `ymyl-content-rules.md`: rules every page must meet before publishing.
- `financialservice-schema.template.json`: a schema skeleton. Every field marked `FILL` must be copied from text that is visible on the page. Remove any field you cannot fill.

## What is needed to go further

1. The live site's code, or an export of its pages.
2. The legal business name, the services offered, and any licence or registration the firm holds, with the regulator's register entry for each.
3. Search Console and Bing Webmaster access for pfsvc.com.pk through the connected Chrome. It was not connected in this run.
